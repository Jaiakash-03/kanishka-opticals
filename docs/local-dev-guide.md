# Local Development Guide

This guide explains how to set up the Kanishka Opticals repository on your local Windows/macOS/Linux machine.

## Prerequisites
- Node.js 20 LTS
- PNPM version 9+ (`npm install -g pnpm`)
- Docker Desktop (for Postgres, Redis, Meilisearch)

## 1. Initial Setup

1. **Clone the repository** (if applicable):
   ```bash
   git clone <repository_url> e:\OPTICALS
   cd e:\OPTICALS
   ```

2. **Install dependencies**:
   ```bash
   pnpm install
   ```

3. **Environment Variables**:
   Copy the example config:
   ```bash
   cp .env.example .env
   ```
   (The `.env` file should remain in the root directory. Turborepo handles passing it to the apps.)

## 2. Start Infrastructure

Start the local database, cache, and search engine:
```bash
cd infra/docker
docker-compose up -d
```
Check if containers are running: `docker ps`. You should see `kanishka_postgres`, `kanishka_redis`, and `kanishka_meili`.

## 3. Database Migration & Seeding

1. **Apply Migrations**:
   This pushes the Prisma schema to the local Postgres database.
   ```bash
   pnpm db:migrate
   ```

2. **Seed the Database**:
   This populates the database with test users, stores, brands, categories, and 50 dummy products.
   ```bash
   pnpm db:seed
   ```

## 4. Running the Apps

Start the development servers for both Next.js (Web) and NestJS (API) simultaneously using Turborepo:
```bash
pnpm dev
```

- **Frontend (Web)**: `http://localhost:3000`
- **Backend (API)**: `http://localhost:3001`
- **API Swagger Docs**: `http://localhost:3001/api/v1/docs`

## 6. Helpful Commands

- `pnpm lint`: Run ESLint across all apps and packages.
- `pnpm typecheck`: Run TypeScript compiler in strict mode without emitting files.
- `pnpm build`: Build all apps and packages for production.
- `pnpm db:studio`: Open Prisma Studio to view database tables visually at `http://localhost:5555`.
